# --- Stops ---
# Space-separated stop IDs. Each stop may take an optional route filter after
# ":", a comma-separated list of tokens:
#   bare route (e.g. Q)  -> pin:  always shown, "No service" when not arriving
#   !route     (e.g. !R) -> mute: never shown, even when arriving
# With no tokens, every arriving route is shown. Examples:
#   R30N         every route arriving at R30N
#   R30N:Q       all arrivals, plus "No service" for Q when it's down
#   R30N:Q,!R    always Q (No service if absent), hide R, show the rest
# A stop may also take @minutes, the walk to that platform: R30N@4, or
# R30N@4:Q,!R. The device keeps it (the server never sees it); the board layout
# hides trains sooner than that and lights the one to leave for now. A platform
# without one takes its station's other platform's.
stops: R30N A41N A42N 233N

# LIRR trips, each FROM>TO by LIRR station code, space-separated: the trains
# leaving FROM that stop at TO. The board shows each like a station: FROM's
# name on top, then one row with TO's name and the next departures. @minutes
# is the walk to FROM, as for a stop.
# lirr: ATL>JAM@9

# Citi Bike stations, by short station number, space-separated. The docks app

# station_information feed ("short_name"), at
# https://gbfs.lyft.com/gbfs/2.3/bkn/en/station_information.json
# These two are both ends of Willoughby St between Ashland Pl and Fleet St.
# bikes: 4587.02 4628.05
